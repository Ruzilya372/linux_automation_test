***Тестовое задание для стажировки:автоматизация развертывания задачив планировщике cron.***

Скрипт на Bash автоматически создает конфигурационный файл для системного cron, настраивает задачу
и выставляет необходимые права доступа.

Как запустить:
1. лонируйте репозиторий или скачайте скрипт.
2. Дайте права на выполнение комадой:
   ```chmod +x deploy_cron.sh```
